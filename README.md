# 🤖 Jarvis Desktop Voice Assistant

Jarvis is a simple **Python-based Desktop Voice Assistant** that can listen to voice commands and perform different tasks on your computer.

This project is created and maintained by **Rahul Verma**.

## 🚀 Features

Jarvis can be extended to perform tasks such as:

- 🎙️ Listen to voice commands
- 🗣️ Speak responses
- 🌐 Open websites
- 🔍 Search on Google
- ▶️ Open YouTube
- 🕐 Tell the current time
- 📅 Tell the current date
- 💻 Open desktop applications
- 📂 Perform basic system tasks
- 🤖 Answer basic questions
- 🔊 Work as a personal desktop assistant

More AI-based features can be added in the future.

---

## 🛠️ Technologies Used

- Python
- Speech Recognition
- Text-to-Speech
- PyAudio
- Python Libraries
- Voice Command Processing
